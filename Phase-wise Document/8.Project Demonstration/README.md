# LegalEase

**Date:** 25 September 2026  
**Team ID:** SWTID-2026-9230  
**Project Name:** LegalEase

LegalEase is an AI-assisted legal-document generation application using a Streamlit frontend, FastAPI backend, and Google Gemini for drafting.

## Features
- Employment contracts
- NDA documents
- Lease documents
- Service/freelance contracts
- Offer letters
- General/custom documents
- Guided inputs
- AI-assisted document generation
- Editable output
- TXT/DOCX/PDF export
- REST API
- Demo mode and error handling

## Setup
1. Install Python.
2. Create and activate a virtual environment.
3. Install dependencies from `requirements.txt`.
4. Add the Gemini API key to `.env`.
5. Start the FastAPI backend.
6. Start the Streamlit frontend.
7. Open the Streamlit application in a browser.

## Note
LegalEase provides AI-assisted drafts. Generated documents should be reviewed by a qualified legal professional before real-world legal use.
